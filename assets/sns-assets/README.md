## デザインメモ
- 背景: `#FAFAF8` → `#EDF4F0` の135°グラデーション
- 右側に App Icon と同じ重なる二円のグラフィック（セージ濃 / 淡 / 重なり）
- 左側にハンドル・ワードマーク・タグライン
- プロフィールアイコンは `icon-assets/` の 400×400 を流用
