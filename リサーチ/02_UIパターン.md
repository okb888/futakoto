# 02 UIパターンリサーチ

カップル/夫婦/日記/感情系アプリの主要画面・UIパターンを整理し、本アプリのMVP最小画面リストとワイヤーフレーム案を提示する。

## 1. 主要アプリのUI構成（実機/紹介記事ベース）

### 1-1. Between（カップル特化・老舗）

- **ホーム**: カップル写真をトップに大きく配置、記念日カウント表示
- **チャット**: 二人専用トーク（既読・スタンプあり）
- **アルバム**: 写真を無制限保存、自由にデコレーション
- **カレンダー**: 共有スケジュール
- **メモ**: 共有メモ
- 構造: タブバー4-5個、トップにカップル名/写真

### 1-2. Pairy（日本・カップル特化）

- ホーム＋記念日カウント
- 質問カード（「もし宝くじに当たったら？」等）
- 行きたい場所リスト
- デート提案（季節・人気店情報）

### 1-3. Paired（英・関係性専門家監修）

- **デイリー質問**: 1日1問。**両方が答えるまで相手の答えは見えない**（重要なUX）
- **クイズ・エクササイズ**: 関係性ジャンル別（恋愛・お金・親密度等）
- **ガイド付きコース**: 動画/テキストで段階的に学ぶ
- **記念日カウンター**

### 1-4. Lovewick（米）

- 1000+質問ゲーム
- デートアイデアライブラリ
- Forget-Me-Nots: 相手の好み（色・食べ物）メモ
- メモリータイムライン: 共有フォトアルバム＋ジャーナル
- ウィッシュリスト
- **Relationship Pulse Journal**（カップルムードトラッカー）

### 1-5. 記憶の木（カップル交換日記）

- 毎日1問同じ質問
- 2人が答えると森に水がまかれ、木や花が育つ（ゲーミフィケーション）
- 写真添付可
- アルバム・記念日カウントダウン

### 1-6. Locket / Loveit.（写真ウィジェット型）

- ホーム画面ウィジェットに相手の写真がリアルタイム表示
- ハグ・キス・タッチ等の「アクション送信」（Loveit.）
- 撮影→1タップ送信が中心UX

### 1-7. Day One（汎用ジャーナル・参考）

- タイムライン表示（カード型）
- カレンダービュー（月・年単位で振り返り）
- リッチテキスト（Markdown）+ 写真・音声・手書き
- ムードテンプレ（自作可）
- タグ・お気に入り・検索フィルタ

### 1-8. Daylio（ムードトラッカー）

- **5段階の表情アイコン** + カラー（rad/good/meh/bad/awful）
- アクティビティアイコン複数選択
- ストリーク表示
- 月間カレンダー（マス目に色）
- 統計グラフ（気分平均、活動相関）

### 1-9. muute（AIジャーナル）

- 自由記述メイン
- 感情タグ付け
- 週次/月次でAIによるインサイトレポート
- 検索＋振り返り機能

### 1-10. Stoic（ジャーナル）

- **スライダー式ムードチェックイン**（リアルタイムで説明文が変化）
- 短いガイド付きジャーナル
- 睡眠・気分の記録

### 1-11. Feelyou（感情共有SNS）

- 感情ごとにフォント変化
- 公開した日記に他者が「共感・応援・感動」リアクション
- 公開・非公開切り替えあり

### 1-12. TimeTree（共有カレンダー・参考）

- 複数カレンダー切替（家族・カップル・仕事）
- 予定毎にチャット可能
- 写真アルバム
- 2026年UXリニューアルで「ホームカレンダー」「みつける」追加

## 2. 共通する画面構成（パターン抽出）

| 画面カテゴリ | 含まれる要素 |
|---|---|
| **ホーム/ダッシュボード** | パートナー名・記念日カウント・今日の質問 or 気分入力導線・最新の共有投稿 |
| **入力画面** | 気分/感情選択（絵文字・色・スライダー） / テキスト / 写真 / 公開範囲切替 |
| **タイムライン/フィード** | 二人の投稿が時系列で並ぶ。リアクション・コメント可 |
| **カレンダー/振り返り** | 月単位で気分カラーや投稿数を可視化 |
| **質問/プロンプト** | 1日1問。相手が回答するとアンロック |
| **プロフィール/設定** | 通知・プライバシー・パートナー連携・テーマ |
| **アルバム/メモリー** | 写真コレクション・ハイライト |

## 3. 感情共有・気分入力UIの代表パターン

| パターン | 採用例 | 特徴 | 採用判断 |
|---|---|---|---|
| **絵文字スコア（5段階）** | Daylio / Reflectly | アイコン+色。タップ1回で完結。最速 | 直感的。MVPに最適 |
| **スライダー式** | Stoic | 連続値で微妙な状態を表現。リアルタイム説明文変化 | 表現豊かだがタップ数増 |
| **感情タグ複数選択** | muute / Daylio | 「嬉しい/疲れた/不安」等を複数選択 | 表現の解像度が上がる。MVP第二段階で追加候補 |
| **カラーパレット型** | Moodistory | 色だけで気分を表現。視覚的 | カラーブラインド対応必要 |
| **自由記述メイン** | Day One / muute | テキスト主体。感情はオプション | 重い。継続率下がりやすい |
| **質問プロンプト型** | Paired / Kindred / 記憶の木 | 「今日相手に感謝したことは？」等で書き出しを誘導 | 忙しい人に書く理由を与える。MVPで検討 |

### 推奨: 5段階絵文字 + 感情タグ（任意）+ 自由記述（任意）の三層構造

## 4. 公開/非公開を切り替えるUIの代表パターン

| パターン | 採用例 | UI |
|---|---|---|
| **トグルスイッチ（公開↔非公開）** | Feelyou / 多くの日記アプリ | 投稿画面下部に1スイッチ |
| **3段階セレクタ（自分のみ/パートナーのみ/全公開）** | Day One共有設定 | ラジオボタン3つ |
| **デフォルト非公開＋明示シェア** | muute / Stoic | 書いた後に「シェアする？」と確認ボタン |
| **両者ロック型（相手も書いたら見える）** | Paired / 記憶の木 | 公開非公開ではなく"同期解錠"。心理的安全性高い |
| **アイコン切替（鍵🔒/二人👫/世界🌐）** | 一部SNS | アイコンで状態表示 |

### 本アプリでの推奨

- **デフォルト「ふたりだけ」**（投稿の中心）
- **任意で「自分だけ（非公開メモ）」** に切替可能
- **「両者ロック型」を一部質問機能に採用**（"今日の質問"のみ、両方答えたら相手の答えが見える）
- 公開SNSはMVP対象外

## 5. MVPで採用すべき最小画面リスト（5画面）

個人開発・MVP前提。コア体験「忙しい毎日でお互いの気持ちを伝える」に絞る。

| # | 画面名 | 役割 | 主要要素 |
|---|---|---|---|
| 1 | **ホーム** | 起動直後に「今日の気持ちを伝える」導線を最短で提供 | パートナー名・連続記録日数・今日の質問カード・最新投稿1件・大きな"+"ボタン |
| 2 | **投稿（入力）** | 気持ちを記録・共有 | 5段階絵文字 → 感情タグ任意 → 一言メモ任意 → 写真任意 → 公開範囲（ふたり/自分のみ）→ 投稿 |
| 3 | **タイムライン** | 二人の投稿を時系列表示 | 日付グループ・投稿カード・1タップ既読/リアクション（ハート・抱きしめる等） |
| 4 | **振り返り（カレンダー）** | 月単位で気分を可視化 | カレンダーマスに色（自分の気分カラー）・タップで詳細・パートナーの気分も並列表示 |
| 5 | **設定** | アカウント・通知・パートナー連携 | プロフィール・パートナー招待コード・通知ON/OFF・テーマ・ログアウト |

### 拡張候補（フェーズ2以降。MVPには含めない）

- 質問プロンプト機能（Paired型・両者ロック）
- 共有アルバム
- 記念日カウントダウン
- インサイトレポート（週次AI分析）
- ウィジェット（Locket型）

## 7. 実装優先順位（推奨）

1. **画面1〜3（ホーム・投稿・タイムライン）**: コア体験。ここだけで価値が成立する
2. **画面5（設定・パートナー連携）**: 招待フローは早期に必須
3. **画面4（カレンダー振り返り）**: 継続率向上のため早めに実装したい
4. ウィジェット・質問機能・アルバムはフェーズ2へ

## 8. デザイン原則の提案

- **タップ数を最小化**: 投稿は3タップ以内で完結（気分→ふたりだけ→送信）
- **強制しない**: メモ・タグ・写真はすべて任意
- **静かなトーン**: 蛍光色・派手なエフェクトは避ける（夫婦・大人向け）
- **既読より反応**: 既読表示よりリアクション（ハート・抱きしめる）を強調
- **デフォルトは"ふたりだけ"**: SNS化させない設計
