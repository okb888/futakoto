## 2. 命名パターン分析

| パターン | 説明 | 例 |
|---|---|---|
| 短い英単語1語型 | 強くシンプル。覚えやすいが商標衝突しやすい | Paired / Lasting / Honi / Kindred / Daylio / muute / Stoic |
| 関係性ワード型 | "Couple" "Pair" "Two" "Us" 等を直接使う | Couples / Pairy / OurCouple / Couple Widget |
| 接続・絆ワード型 | between, link, knot, bond など「つなぐ」表現 | Between / Lovewick / Loveit. |
| 感情・愛ワード型 | Love / Heart / Feel をストレートに使う | Lovewick / Loveit. / Feelyou |
| メタファー・自然物型 | 木・光・部屋など育つ・包むイメージ | Couple Tree / 記憶の木 / Locket（ロケットペンダント）|
| 造語・短縮系 | 既存単語の短縮や混合 | Daylio (Day+lio) / muute (mute+myのもじり) / Pairy (Pair+y) |
| 和語・ひらがな型 | 柔らかさ・親しみ。日本市場で強い | ににににっき / 記憶の木 / 気分手帳 / ふたり会議 |
| 動詞・行為型 | 「やる」をそのまま名前に | Lasting（続く）/ Paired（ペアになる）|
| 数詞型 | "2" "Two" "Day One" など数で関係を示す | Day One / The Couple |
| 所有・代名詞型 | "Our" "We" "Us" で2人を表す | OurCouple / Habi（"Habit Buddies"由来？）|

### 観察される傾向

- 英語アプリは **2音節以下の短い造語** が主流（Paired, Honi, Habi, Daylio）
- 日本語アプリは **ひらがな or 漢字2-4字** で柔らかい印象を狙う（記憶の木、ふたり会議、気分手帳）
- 「カップル」「ペア」をストレートに付ける名前は**結婚済み夫婦には刺さりにくい**（夫婦は"Couple"より"Us""ふたり"を好む傾向）
- 感情共有を強調するなら **Feel系・Heart系** より **静かな絆系（Bond, Knot, Tide, Lull, Hush）** の方が落ち着いた大人向けになる

## 3. このアプリにふさわしい名前案 10選

「忙しい毎日の中で、お互いの気持ちを伝える」という価値を踏まえ、**夫婦・落ち着いたトーン・短くて発音しやすい・既存衝突しにくい** を基準に提案。

### 英語ベース（5案）

| # | 名前 | 命名意図 | ドメイン取得可能性の所感 |
|---|---|---|---|
| 1 | **Tide** | 潮の満ち引きのように、毎日の小さな気持ちが行き交うイメージ。短く強い1音節 | tide.app は空きの可能性高、tideapp.com / tide.love 等は要狙い。tide.com は既存（フィンテック）あり |
| 2 | **Lull** | 静けさ・優しい合間。忙しい日常の中の小休止＝相手と気持ちを通わす時間 | 4文字短語は競合多いがニッチ用途で取得余地あり。lullapp.com / lullus.com 等 |
| 3 | **Knot** | 結び目。夫婦の絆を結ぶ。短くロゴ化しやすい | knot.com はTheKnot（米国大手結婚情報）が押さえる。**衝突リスク高**。knotapp / weknot などへ逃がす必要あり |
| 4 | **Hush** | 静かな声で打ち明ける。穏やかな気持ち共有 | hushapp.com 競合多。.love .us などサブで狙う |
| 5 | **Pace** | お互いの「ペース」を尊重しながら気持ちをやり取り。短く意味も両立 | pace.com はNVIDIA系ブランドで取得困難。pace.love / pacecouple.com など派生で |

### 日本語ベース（5案）

| # | 名前 | 命名意図 | ドメイン取得可能性の所感 |
|---|---|---|---|
| 6 | **きづき** | 相手への「気づき」と自分の「気付き」のダブルミーニング。ひらがなで柔らかい | kizuki.app 等は要確認。一般語のためApp Store内競合は出やすい。漢字違いで「氣づき」差別化案も |
| 7 | **しおり** | 日々のページに挟む栞（しおり）。今日の気持ちを1ページとして残すメタファー。日記アプリと親和性高 | shiori.app / shiori-app.com 等。shioriは技術系プロダクト名でも使われがちだが、夫婦アプリ領域では空き |
| 8 | **ふたごと** | 「ふたり」+「ごと（事・言）」の造語。"夫婦の出来事と言葉"を端的に | 造語のため衝突しにくい。futagoto.com / .app 取得余地高。**推し候補** |
| 9 | **そっと** | 「そっと伝える」の副詞。控えめさ＝忙しい日でも負担なく気持ちを共有 | sotto.app / sottoapp.com 等。Sotto（イタリア語の音楽記号）と被る可能性 |
| 10 | **よりそう / yorisou** | 寄り添う。夫婦アプリの本質を直接表現。やや長いが意味が強い | yorisou.app 取得余地あり。介護・医療領域で使われる例があるので要確認 |

## 4. 個人的に推す上位3候補

1. **ふたごと** — 造語で商標衝突が少なく、「夫婦の出来事と言葉」を端的に示せる。日本市場で柔らかく刺さる。
2. **Tide** — 1音節で世界展開も視野に。"気持ちは満ちては引く"というメタファーが本コンセプトに合う。商標は要精査。
3. **しおり** — 「日々のページに栞を挟む」という日記アプリのコア体験そのものを表す。個人開発レベルで覚えてもらいやすい。

## 5. 命名時の最終チェックリスト（実装前に確認）

- [ ] App Store / Google Play で同名アプリの有無
- [ ] 商標検索（J-PlatPat for 日本、USPTOで米国）
- [ ] .com / .app / .love などのドメイン空き
- [ ] SNSハンドル（X, Instagram）の取得可否
- [ ] 発音時の誤解（"Hush"を日本人が読みづらい等）
- [ ] ロゴ化したときの視認性（短い名前ほど有利）
