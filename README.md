# ふたこと — 夫婦アプリ開発プロジェクト

> アプリ名: **ふたこと**（futakoto）
> 「一言を、ふたりで」— 一言（ひとこと）の二人版
> SNS: X / Instagram `@futakoto_app`

## コア体験（北極星）

> **忙しい毎日の中で、お互いの気持ちを伝える**

すべての機能・UI・コピーはこの1文に貢献するかで判断する。

## 目的

- AIツールを活用した個人開発→リリース→収益化の経験を積む
- 副業化が目的ではない（学習と実証が目的）

## 解決したい課題

- 子の誕生後、夫婦の余裕が減りモヤモヤが怒りに変わる
- 相手に伝えたいことが言えないまま溜まり、防衛反応の応酬になる
- 「言うために気持ちを奮い立たせる必要がある」というハードルを下げたい

## ターゲット

- 子持ち夫婦（特に20-40代）
- 子フォーカスのアプリ（写真・スケジュール共有）に物足りなさを感じている層
- 感情を言語化しきれず、すれ違いを感じている層

## 差別化ポイント

- 子供情報ではなく**お互いの感情・思考**にフォーカス
- 「自分のみ／共有／下書き」の3分類で、出すか出さないかを後から選べる
- AIによるリライト・壁打ちで、伝えにくいことを伝えられる形に

---

## スコープ（v1.0）

### コア機能（無料）

- ペアリング（1対1のみ・招待コード方式）
- 日記の3分類: `自分のみ` / `共有` / `下書き`
- 絵文字スコア（5段階）
- 履歴閲覧（無制限・テキストのみ）
- 通知（相手が共有したとき）
- 一人モード（後から共有/非共有を選べる）
- AdMob広告

### 課金機能

| プラン | 価格 | 内容 |
|---|---|---|
| 買い切り | ¥980 | 広告非表示 |
| 月額 | ¥500 | AI機能（リライト・壁打ち）+ 広告非表示 |

### 後回し / 削除

- 画像・添付（後回し）
- 子供スケジュール（削除・差別化のため）

### AI機能の優先順位

- v1.1で**AIリライト**を先に実装（モヤモヤ→伝わる文章への変換）
- v1.2で**AI壁打ち**（自分の気持ち整理）

## 技術スタック

| レイヤー | 採用 | 理由 |
|---|---|---|
| フロント | Expo (React Native) | Claude Codeで書きやすい・iOS実機即確認 |
| 認証 | Firebase Auth（メール+Apple Sign-In） | Apple審査でApple Sign-In必須 |
| DB | Firestore | 1対1のリアルタイム同期に最適 |
| 課金 | RevenueCat | 個人開発の事実上の標準 |
| 広告 | Google AdMob | Expoプラグイン対応 |
| AI | Gemini API（Cloud Functions経由） | 安価・APIキーを隠せる |
| 配信 | TestFlight → App Store | 標準 |

**Supabase不採用**: Firebase経験あり・1対1のリアルタイム同期にFirestoreが最適。

## 技術メモ（実装中に判明した事項）

- Expo Go は常に New Architecture（Fabric）ON。`newArchEnabled: false` は無効
- `<Tabs>` が react-native-screens と New Architecture の相性問題でクラッシュ → 暫定で `<Stack>` を使用。タブUIはW4で再挑戦
- Firestore の複合クエリ（where + orderBy）はインデックスが必要 → JS側でフィルタして回避
- `@react-native-async-storage/async-storage` は v2.2.0（expo install で決まるバージョン）を使用
- Firestore ルールは開発中「認証済みユーザーは全部OK」。リリース前に厳密化する
