# ふたこと デザインシステム

このファイルはアプリ全体・マーケティング素材すべての **唯一の真実の源（Single Source of Truth）**。
新しいUIを作るとき、Claude Code / Claude Design / 人間デザイナーすべてが最初にこのファイルを参照する。

---

## ブランド

- **アプリ名**: ふたこと（futakoto）
- **タグライン**: 一言を、ふたりで。
- **コア体験**: 忙しい毎日の中で、お互いの気持ちを伝える
- **ターゲット**: 子持ち夫婦（20-40代）。落ち着いた大人向け
- **トーンの方向**: 静か・あたたかい・余白がある・押し付けない

### NG（避けるべき表現）

- 蛍光色・派手なグラデーション
- 過剰な装飾・キラキラエフェクト
- ハート飛びすぎ・ロマンス強調しすぎ
- 「カップル」より「ふたり」を使う
- 既読プレッシャーを生む表現
- 子供を全面に出す（子フォーカスアプリと差別化）

### OK（積極的に使う）

- 自然光のような明るさ・くすみ系
- 余白・間
- 手書き感・温かみ
- 落ち着いたタイポグラフィ
- 共有・受容・寄り添いの表現

## タイポグラフィ

iOSではシステムフォント（SF Pro / Hiragino Sans）を使用。Android では Noto Sans。
ウェブ（ランディングページ）では `-apple-system, BlinkMacSystemFont, 'Hiragino Sans', sans-serif`。

### フォントサイズ

| 用途 | サイズ | weight |
|---|---|---|
| アプリロゴ表示 | 28-40 | 700 |
| 画面タイトル | 16-18 | 600-700 |
| セクションタイトル | 13-14 | 700 |
| 本文 | 14-15 | 400 |
| サブテキスト | 12-13 | 400-600 |
| 弱・補助 | 10-11 | 400 |
| 招待コード表示 | 32 | 600 (Courier等幅) |

### letter-spacing

- ロゴ「ふたこと」は letterSpacing: 3-4
- セクションタイトルは letterSpacing: 1
- それ以外は 0

## コンポーネントのトーン

### ボタン

- プライマリ: 背景 `#7B9E87` / 文字 白 / 角丸 12px
- セカンダリ: 背景 白 / ボーダー `#7B9E87` / 文字 `#7B9E87`
- AIボタン: 背景 `#F3EDFA` / 文字 `#7C5BB7` / 「✨」プレフィックス推奨

### カード

- 背景 白 / 角丸 12px / 左ボーダー4pxで気分カラー
- パディング 16px
- マージン 横16px / 下10px

### 入力欄

- 背景 白 / ボーダー `#E0E0E0` 1px / 角丸 12px
- パディング横14-16 / 縦12-14
- placeholder色 `#BBB`

### FAB（投稿ボタン）

- 円形 56×56 / 背景 `#7B9E87` / 文字 `+` 28px 白
- 右下に配置 (bottom 16-32, right 24)
- shadow: black 0,2 / 0.2 / 4

## アイコン使用ルール

### アイコンライブラリ

**Phosphor Icons** を採用（`phosphor-react-native`）。理由: 温かみと現代性のバランスが取れている・線画なので静かな大人向けトーンに合う・6種類のweightで表現の幅がある。

### 絵文字（残すもの）

絵文字は **気分表現にだけ** 使う。それ以外はPhosphorアイコンに統一する。

- **気分スコア（5段階）**: 😣😔😐🙂😊（必須・差し替え不可）

- タブアイコン: 24px

### 装飾絵文字の禁止

- 🎉 ✅ 🔥 💯 等の装飾絵文字はUIに使わない
- 文章中の絵文字も最小限
- メールやSNS共有テキスト内の絵文字はOK

## 写真・画像トーン

ランディングページ・App Store スクショに使う場合:

- **避ける**: ストックフォト感のある夫婦写真・キラキラ・派手
- **採用**: モノトーンに近いブランドカラー化された抽象画像、または実機UI画像のみ
- **マーケ用キービジュアル**: 二つの円が重なるグラフィック・対話の吹き出しモチーフ・カレンダーの色のグリッドなど抽象的に

---

## モーション・トランジション

- フェードイン: 200-300ms
- スライドアップ（モーダル）: 300ms
- ボタンタップ: opacity 0.6
- スプリングは控えめ（過剰なバウンスNG）

---

## ロゴ・ワードマーク

「ふたこと」のロゴ表現:

- ひらがな4文字をベースとする
- 太めのウェイト（700）+ letterSpacing 3-4
- カラー: `#2D2D2D` または `#7B9E87`
- アイコン化する場合: 二つの円が重なる / または「ふ」と「こ」を絡める形
