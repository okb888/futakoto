# UI修正ログ 2026-05-17

## ホーム画面

### H-1: カード左ボーダーの二重解消
**問題**: `myEntryWrapper` / `partnerEntryWrapper`（投稿者色 3px）と `EntryCard` の `borderLeftColor`（感情色 4px）が重複していた。  
**修正**: `app/(app)/index.tsx` の `myEntryWrapper` / `partnerEntryWrapper` スタイルからボーダーを削除。感情色ボーダー（EntryCard側）のみ残す。

### H-2: 絵文字タップ → インライン展開に変更
**問題**: 絵文字タップでモーダルが開く二重フロー。モーダルに顔文字ラベル・共有範囲選択がなかった。  
**修正**:
- `Modal` コンポーネントを廃止
- 絵文字タップで `selectedMood` をセット → インラインで展開
- 各絵文字の下に理由ラベル（つらい〜いい感じ）を常時表示
- 展開後に テキスト入力 + 共有範囲トグル（ふたりに共有 / 自分だけ）+ 伝えるボタン が表示
- `visibility` state を追加し `addEntry` に渡す（従来は `'shared'` 固定）

## 振り返り画面

### V-1/V-2: 種別タブ追加 + フィルタータブから「相談」「自分/相手」を削除
**問題**: 種別（投稿/相談）がフィルターパネル内に隠れていた。「相談」がフィルタータブに混在していた。  
**修正**: `app/(app)/calendar.tsx`
- `FilterType` を `'all' | 'favorite'` に縮小
- `calendarTypeFilter: 'all' | 'entry' | 'consultation'` state を新規追加
- カレンダービューのフィルター行を「種別（すべて/投稿/相談）| お気に入り/すべて」の構成に変更
- `selectedDayRecords` のフィルタリングロジックを `calendarTypeFilter` ベースに更新

### V-3: 感情フィルターの縦ズレ修正
**問題**: ログビューのフィルターパネルで「全部」テキストが絵文字チップより上にずれていた。  
**修正**: `filterRow` に `alignItems: 'center'`、`filterChip` に `alignItems: 'center', justifyContent: 'center'` を追加。

### V-4: 相談ログタップ後のリセット
**問題**: 相談タブ経由でログが表示された後、他のタブに移動してもリセットされなかった。  
**修正**: `useFocusEffect` のクリーンアップ関数で `setViewMode('calendar')` と `setLogTypeFilter('all')` を呼び出し。

### V-5: カレンダー月移動スワイプロック修正
**問題**: 過去月に移動するとカレンダー全体をオーバーレイが覆い、矢印ボタン・スワイプが効かなくなっていた。  
**修正**: `calendarOverlay`（全体を覆うView）を廃止。過去月のロックは選択日の記録エリア（下部）にプレミアム訴求ブロック（`pastMonthBlock`）を表示する形に変更。カレンダー本体の月移動は常に可能。

### V-6: 「今月」ボタンの追加
**修正**: 過去月表示中のみカレンダー右上に「今月」ボタンを表示。タップで `currentMonth` を現在月にリセット。

### V-7: カレンダー投稿者フィルターの重複削除
**問題**: カレンダー上部に「自分/パートナー」ボタン、下部フィルタータブにも「自分/相手」が並存していた。  
**修正**: V-1/V-2でフィルター定義を縮小（`'all' | 'favorite'` のみ）したことで自動的に解消。

### V-8: 「過去月の振り返りはプレミアム」バナーの削除
**問題**: 無料ユーザーに毎月固定でプレミアムバナーが表示されていた。  
**修正**: `premiumHint` ブロックを削除。課金誘導は V-5 の `pastMonthBlock`（過去月選択時のみ表示）に一本化。
