## 0. 共通方針

### 統一する要素
- **アカウント名**: 全SNS「ふたこと」で統一
- **ユーザーネーム**: `@futakoto_app`（X / Instagram で取得済）
- **アイコン**: アプリアイコン（[`assets/icon.svg`](../assets/icon.svg)）を全SNS共通で使用
- **トーン**: 静か / あたたかい / 余白がある / 押し付けない

### bio に必ず入れる3要素
1. プロダクトの一言定義（30秒で気持ちを共有）
2. 人物性（個人開発／離婚を覚悟した経験から）
3. リリース時期（2026年6月）

### アイコン採用前の必須チェック
アプリアイコンは「角丸正方形」前提。X/IG/note は**円形クロップ**されるため、4隅の要素が切れる可能性。**事前にプレビュー確認必須**（[`assets/icon.svg`](../assets/icon.svg) を円形マスクで表示する）。

## 4. ヘッダー画像生成プロンプト（Claude Design 用）

### 共通の前置き（毎回先頭に貼る）

```
ふたこと（夫婦の気持ち共有アプリ）の SNS マーケティング素材を作ってください。
ブランドガイドラインは添付の system.md に従う。

# ブランドの核
- アプリ名: ふたこと（ひらがな4文字）
- タグライン: 「一言を、ふたりで。」
- トーン: 静か / あたたかい / 余白がある / 押し付けない
- メイン色: warm white #FAFAF8（背景） / muted sage green #7B9E87（アクセント） / dark text #2D2D2D
- ロゴは「ふたこと」をひらがな4文字、weight 700、letterSpacing 3-4
- ビジュアルモチーフ: 二つの円が重なるグラフィック / 対話の吹き出し / カレンダーの色グリッド

# 絶対NG
- ストックフォト感のある夫婦写真
- ハート連発、キラキラ、グラデ強め、蛍光色
- 「カップル」という言葉
- 子供を全面に出す
- 既読プレッシャーを生む表現
- 装飾絵文字（🎉✅🔥💯等）
```

> **使い方**: Claude Design に [`.design/system.md`](../.design/system.md) をアップロード → 上記前置き＋下記いずれかを送信。

### ① X ヘッダー画像（1500 × 500px）

```
サイズ: 1500 × 500px（X / Twitter ヘッダー専用）

# 構図
- 背景: warm white #FAFAF8 ベース、左右に sage green の柔らかいグラデーションを薄く敷く
- 中央: タグライン「一言を、ふたりで。」を 大きく配置（フォント weight 700、color #2D2D2D、letterSpacing 4）
- タグラインの下に小さく: 「futakoto - 夫婦の気持ちを30秒で共有するアプリ」（color #888、letterSpacing 1）
- 左側: 二つの円が重なる抽象グラフィック（sage green #7B9E87 と soft sage #C8D8CC、透明度40-60%、ふんわり重なる）
- 右側: 余白多め（プロフィール画像が右下重なる位置を考慮して避ける）

# 重要
- X はプロフィールアイコンが「左下」に円形クロップで重なる。左下 200×200px は何も置かない
- スマホ表示では上下が少しトリミングされる前提で、上下16%は安全領域として情報を入れない
- 押し付けがましさゼロ。広告感を完全に排除
```

### ② note ヘッダー画像（1280 × 670px）

```
サイズ: 1280 × 670px（noteクリエイターページのヘッダー）

# 構図
- 背景: warm white #FAFAF8、ごく薄い縦グラデーション
- 中央寄り左: 「夫婦のしんどさを、夫側から書きます。」（フォント weight 600、color #2D2D2D、サイズ大きめ）
- その下に小さく: 「個人開発アプリ『ふたこと』を作っています。」(color #555)
- 右側: アプリのカレンダー画面（気分ヒートマップ）の縮小モックを 25-30度の浅い傾きで配置、ドロップシャドウ薄め
- カレンダーの気分色は実際のアプリパレットを使用（赤 #E57373 / オレンジ #FFB74D / 黄 #FFF176 / 緑 #AED581 / 水色 #81D4FA）

# 重要
- noteは記事タイトルが上に被ることがあるので、上部15%は重要情報を置かない
- カレンダーモックは「これがアプリの中身です」と一目でわかる程度のディテール
- 静謐な日記の表紙のようなトーン
```

### ③ Instagram グリッド統一用OGP / 単独投稿テンプレ（1080 × 1080px）

```
サイズ: 1080 × 1080px（Instagram フィード正方形）

# 構図（テンプレート）
- 背景: warm white #FAFAF8
- 中央上: 「ふたこと」ロゴ（ひらがな4文字、weight 700、letterSpacing 4、color #7B9E87）
- 中央: 引用文（最大80字、フォント weight 400、color #2D2D2D、行間 1.8）
- 中央下: 二つの円が重なる小さな抽象モチーフ（sage green、20-30px）
- 上下に十分な余白（パディング各 120px）

# 引用文サンプル（差し替え可能・5種類のバリエーション）
1. 「『疲れてる？』と聞いただけで、何かが変わった日があった。」
2. 「夜寝る前の30秒を、ふたりのために。」
3. 「言いたいけど、言えない。その積み重ねが、距離になる。」
4. 「関係が終わってるんじゃない。ねぎらい機能が止まってるだけかもしれない。」
5. 「忙しい毎日に、ふたりだけの一言を。」

# 重要
- 同じ構図で5枚作って、Instagramのグリッド統一感を出す
- 引用文は「物語の予告編」のようなトーン。説明的にしない
```

### ④ Instagram ハイライトカバー（1080 × 1920px、4種類）

```
サイズ: 1080 × 1920px（Instagramストーリー / ハイライトカバー）
4種類セットで作成

# 共通設計
- 背景: warm white #FAFAF8
- 中央: Phosphor Icons から選んだ細線アイコン1個（120×120px、色 #7B9E87）
- アイコン下: ラベル（フォント weight 600、color #2D2D2D、サイズ 36px、letterSpacing 2）
- 上下とも余白多め

# 4種類の中身
| # | ハイライト名 | アイコン | ラベル |
|---|---|---|---|
| 1 | 開発の記録 | Notebook（Phosphor） | 開発の記録 |
| 2 | 画面ギャラリー | Squares | 画面 |
| 3 | リリース予定 | Calendar | リリース |
| 4 | よくある質問 | Question | Q&A |

# 重要
- ハイライトはInstagramで円形クロップされる（中央600×600px領域のみ表示）
- アイコンとラベルは中央600×600px以内に収める
```
