**策定日**: 2026-05-09
**目的**: ふたことの集客のための発信（note / X / Instagram）に使う、岡部広之自身の夫婦・家族・感情の記録を一覧化し、運用する。
**関連**: [`release-status.md`](./release-status.md) E. SNS運用 / F. LP修正

## 0. 運用ルール

### 採用基準
- 自分自身が体験した感情・気づき・対話の記録であること
- 読者（特に「諦めかけている妻」ペルソナ）に届く要素を持つこと
- ふたことのコア価値（ねぎらい機能の再起動・言葉にできない気持ちの言語化）と地続きであること

### 機微度の判定基準
- **極高（🔴）**: 妻・前妻・娘の固有名詞、性的な話、妻の発言の直接引用が含まれる。**そのまま公開不可**。抽象化すれば一部使える
- **高（🟠）**: 家族のプライベートな出来事を含む。**妻同意必須**で骨格のみ使う
- **中（🟡）**: 自分側の内省主体だが家族の存在を含む。**抽象化＋妻に事前共有**で公開可
- **低（🟢）**: 父親・夫としての一般的な気づき。**そのまま公開可**

### 妻同意の運用
- 機微度🔴🟠は note 公開前に妻に下書きを見せる
- 妻の発言を直接引用する場合は引用許諾を文書で残す
- 娘（心春）は固有名詞・年齢の特定情報を伏せる（「赤ちゃん」「乳児期」までで止める）
- 引用許諾がもらえない箇所は「相方」「片方」など抽象化する

### ステータス
- `未着手` / `下書き中` / `妻同意待ち` / `note公開済` / `X抜粋済` / `IG抜粋済` / `非公開保管`

## 3. note 公開順の推奨案（叩き台）

リリースは6月下旬予定。note は5本完結シリーズで以下の順序を推奨:

| # | テーマ（仮タイトル） | 中核ストック | 機微度 | 想定公開時期 |
|---|---|---|---|---|
| 1 | **「子どもが、立った」または「冷蔵庫という、川の中の石」**（人物像導入・温度感の確立） | STK-12 / STK-05 | 🟢 / 🟡 | 6月リリース週 |
| 2 | **「『疲れてる？』と聞いた日に、何かが変わった」**（小さな言葉の力） | STK-08 / STK-07 | 🟢 | 6月中 |
| 3 | **「離婚を覚悟した日、一日で景色が変わった話」**（クライマックス） | STK-01（抽象化）/ STK-02 | 🟠 | 6月下旬 |
| 4 | **「ワンオペを1日体験して見えた、ねぎらい機能が止まる構造」**（構造分析） | STK-15 / STK-02 / STK-06 / STK-10 | 🟠 | 7月上旬 |
| 5 | **「言葉にならないことを、言葉にする装置を作った」**（プロダクト紹介） | STK-19 / STK-16 | 🟢 | リリース直後 |

**設計思想**:
- 1本目は機微度が低く、岡部さんの人柄・文体が伝わる詩的な記事から入る（信頼を築く）
- 3本目に3/11を配置することで、それまでに読者との関係性が温まっている状態でクライマックスを出せる
- 5本目で初めてプロダクト訴求。それまでは「物語」「気づき」を提供する

**代替案**: 1本目に3/11を持ってくる（「中核資産として前面」方針）。インパクトは最大だが、初見読者への心理的負担が大きい。フォロワーがゼロからのスタートなら段階的展開の方が安全。
